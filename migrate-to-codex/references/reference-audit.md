# Reference audit

Run for each selected source scope before conversion and again on Codex output.

1. Inventory .claude recursively, including hidden files, scripts, references, assets, nonstandard directories and symlinks. Read all relevant text contents, not only SKILL.md. Account for binaries as assets. Identify links leaving the selected scope and report them without silently importing outside data. Do not dump secrets into reports.
2. Build a source-to-destination map for migrated files and skills. The upstream copier only includes scripts/, references/, and assets/ under directory skills; explicitly carry across additional files required by migrated workflows. Do not copy caches, credentials, history or unrelated state.
3. Inspect instructions and supporting code for .claude paths, CLAUDE.md imports, Claude tool names, slash commands, placeholders, environment variables, agent configuration and hooks. Adapt operational references where Codex requires different behavior; retain intentional documentation or support for Claude.
4. Resolve every reference using its actual base: repository root for repo-relative commands, referring document for Markdown links where appropriate, skill root for skill resource instructions, and script location or working directory as established by code. Trace cross-skill calls and imports. For ambiguous bases inspect callers; report unresolved ambiguity rather than guessing.
5. Rewrite references in migrated copies using the destination map. A repo-root command pointing to .claude/skills/shared/scripts/check.py should use .agents/skills/shared/scripts/check.py if that file was migrated. A ../shared/ reference may already remain correct. Changed script layout may require updating parent-directory calculations or working-directory assumptions. Preserve original Claude sources.
6. Verify rewritten static paths exist from their intended bases, cross-skill calls reach migrated skills, and required support files are present. For dynamic paths inspect construction and run safe focused checks where possible; report anything unverified. Search output for remaining Claude references and classify them as intentional or unresolved. Review shared AGENTS.md content even when its symlink needs no conversion.
7. Test changed scripts with isolated fixtures or safe dry runs. Do not execute hooks or external actions merely to validate paths. Run upstream validation too, but metadata checks alone do not establish path correctness. Report unresolved dependencies and preserve repairs on repeat runs.
